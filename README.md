# Guardant Health Monitor

Скрипт для мониторинга доступности USB-ключа Guardant Sign в Linux с функцией занятия сессий компонентов.

## Описание

Скрипт `guardant_health_monitor.sh` предназначен для периодической проверки доступности USB-ключа Guardant и поддержания соединения с ним. Скрипт занимает сессии компонентов при подключении к ключу, что предотвращает конфликты с другими приложениями (аналогично тому, как это делает Guardant Control Center).

## Возможности

- **Периодическая проверка**: Регулярная проверка доступности ключа с настраиваемым интервалом
- **Занятие сессий компонентов**: При проверке занимаются сессии для сертификатов, ключей и контейнеров
- **Множественные клиенты**: Поддержка симуляции нескольких клиентов, подключающихся к ключу
- **Различные методы проверки**:
  - Через утилиты командной строки Guardant (gtt, gcli, gc_cli)
  - Через USB подсистему (lsusb)
  - Через файлы устройств (/dev/bus/usb, hidraw)
  - Через библиотеки Guardant
- **Логирование**: Подробное логирование всех событий с цветным выводом
- **Защита от множественных запусков**: Использование lock-файла
- **Автоматическое восстановление**: Попытки переподключения при потере ключа
- **Гибкая настройка**: Параметры через командную строку или переменные окружения

## Установка

Убедитесь, что установлены драйверы и утилиты Guardant:
```bash
# Для Guardant Sign
sudo apt install guardant-drivers  # Или используйте пакеты от производителя
```

## Использование

### Базовый запуск
```bash
./guardant_health_monitor.sh
```

### Запуск с параметрами
```bash
# Проверка каждые 60 секунд с 3 клиентами
./guardant_health_monitor.sh -i 60 -c 3

# Отключить занятие сессий
./guardant_health_monitor.sh --occupy-sessions false

# Занять только сессии сертификатов и ключей
./guardant_health_monitor.sh --session-components cert,key

# Полный контроль над таймаутом сессий
./guardant_health_monitor.sh -s 20 --session-components certificate,key,container
```

### Запуск с переменными окружения
```bash
GUARDANT_CHECK_INTERVAL=45 GUARDANT_MAX_CLIENTS=3 ./guardant_health_monitor.sh
GUARDANT_OCCUPY_SESSIONS=false ./guardant_health_monitor.sh
GUARDANT_SESSION_COMPONENTS="cert,cont" ./guardant_health_monitor.sh
```

### Тестовый режим (одна проверка и выход)
```bash
./guardant_health_monitor.sh -t
```

## Параметры командной строки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `-i, --interval SECONDS` | Интервал проверки в секундах | 30 |
| `-c, --clients NUMBER` | Количество симулируемых клиентов | 5 |
| `-l, --log FILE` | Путь к файлу логов | /var/log/guardant_health.log |
| `-s, --session-timeout SECONDS` | Таймаут сессии в секундах | 10 |
| `--occupy-sessions BOOL` | Занимать сессии компонентов (true/false) | true |
| `--session-components LIST` | Компоненты для занятия сессий (через запятую) | certificate,key,container |
| `-t, --test` | Однократная проверка и выход | - |
| `-h, --help` | Показать справку | - |

## Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `GUARDANT_CHECK_INTERVAL` | Интервал проверки в секундах | 30 |
| `GUARDANT_MAX_CLIENTS` | Максимальное количество клиентов | 5 |
| `GUARDANT_LOG_FILE` | Путь к файлу логов | /var/log/guardant_health.log |
| `GUARDANT_SESSION_TIMEOUT` | Таймаут сессии в секундах | 10 |
| `GUARDANT_OCCUPY_SESSIONS` | Занимать сессии (true/false) | true |
| `GUARDANT_SESSION_COMPONENTS` | Компоненты для занятия сессий | certificate,key,container |

## Типы компонентов для занятия сессий

| Компонент | Алиасы | Описание |
|-----------|--------|----------|
| `certificate` | `cert` | Сессия работы с сертификатами |
| `key` | `privatekey` | Сессия криптографических операций |
| `container` | `cont` | Сессия работы с контейнерами |

## Примеры использования

### Непрерывный мониторинг с занятием всех сессий
```bash
./guardant_health_monitor.sh -i 30 -c 5
```

### Мониторинг без занятия сессий (только проверка)
```bash
./guardant_health_monitor.sh --occupy-sessions false
```

### Выборочное занятие сессий
```bash
./guardant_health_monitor.sh --session-components cert,key
```

### Запуск в фоновом режиме с логированием
```bash
./guardant_health_monitor.sh -i 60 -l /var/log/guardant_monitor.log &
```

### Комбинирование параметров
```bash
GUARDANT_CHECK_INTERVAL=45 GUARDANT_OCCUPY_SESSIONS=true \
./guardant_health_monitor.sh --session-components certificate --test
```

## Логирование

Скрипт записывает логи в указанный файл (по умолчанию `/var/log/guardant_health.log`) и выводит информацию в консоль с цветовой индикацией:
- 🟢 **INFO** - информационные сообщения (зеленый)
- 🟡 **WARNING** - предупреждения (желтый)
- 🔴 **ERROR** - ошибки (красный)
- 🔵 **Session messages** - сообщения о сессиях (синий)

## Восстановление соединения

При обнаружении потери доступа к ключу скрипт:
1. Логирует ошибку
2. Пытается выполнить повторную инициализацию USB-соединения (требуется root)
3. Выполняет повторную проверку через 5 секунд
4. Продолжает мониторинг

## Защита от множественных запусков

Скрипт использует lock-файл (`/tmp/guardant_health.lock`) для предотвращения запуска нескольких копий одновременно. При обнаружении уже работающего экземпляра новый процесс завершится с ошибкой.

## Примечания

- Для работы некоторых функций (например, переподключения USB) могут потребоваться права root
- Скрипт автоматически определяет установленные утилиты Guardant в системе
- При отсутствии ключа или драйверов скрипт продолжит работу, логируя ошибки
- Занятие сессий помогает предотвратить конфликты с Guardant Control Center и другими приложениями

## Лицензия

Скрипт распространяется "как есть" без гарантий.
